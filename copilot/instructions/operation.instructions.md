現在の環境の Node.js ランタイムは、pnpm 11 以降の `pnpm runtime` でインストールされており、`npm` と `npx` は展開されていない。`npm` ではなく `pnpm`、`npx` ではなく `pnx`（エイリアス: `pnpm dlx`、`pnpx`）を使用すること。

依存関係の変更は、`package.json` や `pnpm-workspace.yaml` ファイルの直接編集ではなく、常にパッケージマネージャー経由で行うこと。

現在の環境は、1Password SSH エージェントを経由した Git コミットまたはタグの署名が有効化されており、SSH キーアクセス要求をユーザーが承認する必要がある。コミットまたはタグの作成に失敗した時は、エラーを報告し、ユーザーの指示を待つこと。署名なしで続行してはならない。
