現在の環境の Node.js ランタイムは、pnpm 11 以降の `pnpm runtime …` でインストールされており、`npm` と `npx` は展開されていない。`npm` ではなく `pnpm`、`npx` ではなく `pnx`（エイリアス: `pnpm dlx`、`pnpx`）を使用すること。

組み込みコマンドとして解釈されることを確実に避けるため、パッケージスクリプトの実行には常に `pnpm run …` を使用すること。

依存関係の変更は、マニフェストファイルの直接編集ではなく、常にパッケージマネージャー経由で行うこと。

現在の環境は、1Password SSH エージェントを経由した Git コミットまたはタグの署名が有効化されている。コミットまたはタグの作成に失敗した時は、ユーザーが席を外しており SSH キーアクセス要求を承認できなかった可能性があるため、エラーを報告して指示を待つこと。
