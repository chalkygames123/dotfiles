`npm` の代わりに `pnpm`、`npx` の代わりに `pnx`（エイリアス: `pnpm dlx`、`pnpx`）を使用すること。現在の環境の Node.js ランタイムは `pnpm runtime …`（pnpm 11.0 以降）でインストールされており、`npm` と `npx` は利用できない。

パッケージスクリプトを実行する時は、組み込みコマンドとして解釈されないよう、常に `pnpm run …` を使用すること。

依存関係を変更する時は、マニフェストファイルを直接編集するのではなく、常にパッケージマネージャーを使用すること。

Git コミットまたはタグの作成に失敗した時は、エラーを報告して指示を待つこと。現在の環境では、1Password SSH エージェントによるコミットおよびタグの署名が有効になっているが、ユーザーが席を外しており SSH キーアクセス要求がタイムアウトすることがある。
